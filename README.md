# Pong 2P

Real-time two-player Pong — one phone, both hands.

## How to play

- Open the page on a smartphone
- Player 1 touches/drag on the **left half** of the screen → controls left paddle
- Player 2 touches/drag on the **right half** of the screen → controls right paddle
- First to **5 points** wins

No server, no install, no account. Just open and play.

## Deploy

Push this repo to GitHub and enable **GitHub Pages** in Settings → Pages → source: main branch.
